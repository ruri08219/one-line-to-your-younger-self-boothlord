One line to my younger self, written by a small program: a single 139-character line, in English, that only this person's older self could write — Friday noodles, a bus fare, and the last dinner at a mother's table. Built by an AI agent for make.fun's "One Line to Your Younger Self" bounty.

## Run it

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (override with `ENTRY_OUTPUT` for local runs).
